## Full description

Masinloc Connect puts useful Masinloc community services and information in one mobile experience.

Browse local Marketplace businesses, discover current job opportunities from trusted providers, keep a Signature Resume, explore Mabayani history, search the Sambal Tina Dictionary, read Discover Masinloc stories and send an incident report to the appropriate response desk.

Public content shown in the app remains connected to the same Masinloc Connect platform used by the website, rather than being maintained as a separate copy.

Highlights:

- Local Masinloc Marketplace discovery
- Current job opportunities with source attribution
- Optional saved jobs and career profile tools
- Mabayani history with documented evidence and source notes
- Searchable Sambal Tina Dictionary
- Discover Masinloc stories and community information
- PNP or MDRRMO incident routing
- Optional GPS location for an incident report, with manual barangay or landmark entry available
- Offline-safe report saving until a connection is available
- Optional passwordless email account for saved and personalized features

No account is required for public browsing or incident reporting.

Masinloc Connect is an independent community platform and should not be represented as an official government application unless that status is formally established outside this release.

## Review notes

- Account creation is optional.
- Account deletion is available inside Profile and from the public deletion URL.
- Device location is only used when the user chooses to attach it to an incident report. Manual location entry is available instead.
- Jobs may link to an external trusted-provider application page.
- Push notifications are not advertised as an active user feature in this release. Provider credentials and notification behavior must be completed before enabling them.
